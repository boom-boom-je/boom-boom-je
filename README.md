## 👋 About boom-boom-je

데이터를 통해 비즈니스 문제를 정의하고, 실질적인 개선안을 도출하는 데 강점이 있는 데이터 분석가입니다. 데이터 분석 부트캠프를 수료하며 데이터 수집 및 분석, 모델링, 자동화 파이프라인 구축까지 분석의 전 과정을 학습하였습니다. 특히, 사용자 로그 데이터 분석 프로젝트를 통해 프레임워크 활용 분석 역량을 길렀으며, 결제 예측 파이프라인 구축 프로젝트를 통해 원본 데이터 로드부터 자동화까지 엔지니어링 전과정을 직접 수행해보았습니다. 진행중인 스터디를 통해 현업 종사자와 협업하여 실무에 가까운 서비스 개발 프로젝트를 수행하고 있으며, 데이터 분석 뿐만 아니라 엔지니어링의 전반적인 프로세스와 서비스 구현에 대한 전문적인 경험을 하고 있습니다. ‘최고가 되기 위해 최선을 다하다 보면 언젠간 최고가 되어 있을것이다.’라는 아버지의 가르침을 따라 언제나 최선을 다하여 최고의 결과를 내는 데이터 분석가로 성장하고 싶습니다.
